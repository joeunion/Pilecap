# ADR sdk-1

**ADR sdk-1 · the SDK's major is the template's.** `pilecap.__version__` reads `TEMPLATE_VERSION`; a product's pin is `scripts/local/template-base` (rule 60's reader). Removing or narrowing a public name — a required parameter added, a parameter removed, a default lost — is a major release; an optional parameter added is minor and silent; a name leaves only through a `DEPRECATED` entry served at least one minor release, which `scripts/divergence_census.sh --against <tag> --sdk` prints at the product's fold. House rule 97 holds it. Rejected: a version independent of the template's (two numbers a product reconciles by hand); `warnings.warn` (a warning filter hides it; `core.log` does not). Trigger to revisit: the SDK published as its own package (D-S6), when it needs a number of its own.
