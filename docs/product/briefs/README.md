# Dispatch briefs — the rung's own copy

> **Holds:** one file per dispatched rung, `docs/product/briefs/<rung>.md`,
> committed **in the rung branch as a docs-only commit** — the brief the PM
> wrote for that builder or verifier: the territory, the criteria pointer, and
> whatever is unusual about the rung, in the shape
> `.claude/skills/product-manager/references/dispatch-briefs.md` gives. It
> merges with the rung and stays beside the work it governed.
> **Must not hold:** the criteria themselves (they are the plan's, in
> `docs/product/cycles/`, verbatim and unmoved), status (`in-flight.md`), or
> order (`queue.md`). A brief points at those; it never restates them.
> **Never in the session's scratchpad:** a dead agent's successor reads the
> tree, not a directory that died with the session
> (`.claude/skills/product-manager/SKILL.md` § The loop, stage 5).
