{% comment %} FRAME `choose_your_password` — design J1-a. The invited person's first screen, and for the first admin of a fresh deployment it is the first screen of the product at all. THREE THINGS ON THIS FRAME ARE READ, NEVER TYPED. The address is the one the invite code was minted for, read back from the person the platform answers for — never off the URL, because a URL is something anybody can edit and this sentence is what tells you whose account you are about to set a password on. The password rule is the organization's own complexity policy, read at render. "At least 8 characters" is what the pinned build's default policy happens to say; a number typed into this file would be a sentence that goes quietly wrong on the first organization that tightens its policy. No policy handed in, no sentence. The expiry is the platform's invite-code lifetime, and the frame says what to do when it has passed — ask the person who invited you — because the one thing somebody holding a dead link needs is the name of their next move. {% endcomment %}
