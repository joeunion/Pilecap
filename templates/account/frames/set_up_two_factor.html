{% comment %} FRAME `set_up_two_factor` — design J2-c. The organization asks for a second step and this person has none enrolled, so enrolment happens HERE rather than on a page in a different visual register. THE QR IS DRAWN BY US, FROM THE URI THE IDENTITY PLATFORM RETURNS — `apps/ accounts/qr.py`, an in-tree encoder, so there is no library and no image to fetch. This frame is its slot; with nothing handed in it draws no figure, which is why the secret is offered as text in its own right and not only as a fallback: a person on a laptop with no camera types it. `Not now` appears only where the platform's login settings say a skip is allowed and for how long — the number is read at render, never typed here. No skip configured, no control: a door that looks available and refuses is worse than no door. It is a BUTTON in its own form for the same reason `Never mind` is one on the previous frame: skipping is a state change, and a link is something a prefetcher follows while the person is still reading. THE LEDE IS OVERRIDABLE AND DEFAULTS TO THE DESIGN'S WORDS. A re-render after a refused code carries no symbol — the platform begins ONE enrolment and the person's app already holds it, so asking for a second secret would replace the one they just scanned — and "scan this" is the wrong instruction on a screen with nothing to scan. {% endcomment %}
